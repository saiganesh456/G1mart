G1 Mart Supermarket — Nellore, AP Confidential & Proprietary

1. Executive Summary & Why PhonePe

G1 Mart (g1mart.in) operates a fast-delivery grocery model serving Nellore, Andhra Pradesh. Choosing PhonePe as the primary online payment gateway provides critical advantages for an Indian grocery e-commerce business:

  • Market Dominance in India: PhonePe commands over 48% of all UPI transactions in India, offering frictionless UPI Intent checkout on mobile devices.
  • Deep UPI App Linking: Customers on Android and iPhone can tap to pay immediately without manually entering their VPA or scanning external QR codes.
  • Higher Payment Success Rates: Fallback options for RuPay Debit cards, VISA/Mastercard, NetBanking, and PhonePe Wallet ensure high conversion rates.
  • Server-to-Server Webhook Security: Direct server callbacks safeguard against dropped user connections, network dropouts, or users closing their browser tab before redirecting.
Current Codebase Readiness

The G1 Mart codebase already contains a pre-built adapter at src/lib/payment/phonepeAdapter.ts implementing the /pg/v1/pay API, Order Status verification (/pg/v1/status), and webhook payload signature checking.

4. End-to-End System Architecture & Flow

The complete transaction lifecycle consists of 7 distinct phases between the customer browser, G1 Mart Next.js server, and PhonePe PG servers:

1
Customer Initiates Checkout (Browser -> Next.js Server)
Customer taps "Pay Online (₹Total)" at https://g1mart.in/payment. The frontend sends the cart items and address to POST /api/checkout/initiate.
2
Server Security & Price Recalculation
serverOrderStore.recalculateOrderTotal() recalculates line totals from database prices to eliminate client tampering. It assigns a unique order ID (G1-XXXXXX) and merchant transaction ID (MT_G1-XXXXXX_timestamp).
3
PhonePe Standard Pay Page Initiation (Next.js -> PhonePe API)
The server creates a Base64-encoded JSON payload and calculates the X-VERIFY SHA-256 header. It posts to https://api.phonepe.com/apis/pg/v1/pay. PhonePe returns a secure hosted URL: instrumentResponse.redirectInfo.url.
4
Customer Redirect & Payment Execution
The customer browser redirects to PhonePe's hosted pay page. The customer authorizes payment via their preferred UPI App (PhonePe, GPay, Paytm) or Card.
5
Channel A: Server-to-Server Webhook (PhonePe -> Next.js)
PhonePe posts an asynchronous callback to https://g1mart.in/api/payment/webhook. The server validates the checksum signature, checks idempotency, updates Supabase orders.payment_status = 'completed', and marks is_paid = true.
6
Channel B: Frontend Redirect & Status Polling
PhonePe redirects the user back to https://g1mart.in/payment/result?orderId=G1-XXXXXX. If the webhook has already resolved, the page confirms instantly. If pending, the page polls /api/orders/{id}/payment-status every 2.5 seconds.
7
Order Dispatch & Real-Time Fulfillment
The order triggers broadcast notifications to the G1 Mart Store Admin dashboard and rider dispatch portal for immediate packing and dispatch.

6. Cryptographic Signature Generation (X-VERIFY)

PhonePe mandates SHA-256 HMAC checksums on every request and webhook to prevent tampering and man-in-the-middle attacks.

6.1 Payment Initiation Checksum (POST /pg/v1/pay)

// 1. Convert JSON payload to Base64 string
const base64Payload = Buffer.from(JSON.stringify(payload)).toString('base64');

// 2. Concatenate base64 string + API endpoint path + Salt Key
const stringToHash = base64Payload + '/pg/v1/pay' + PHONEPE_SALT_KEY;

// 3. Compute SHA256 digest
const sha256 = crypto.createHash('sha256').update(stringToHash).digest('hex');

// 4. Append Salt Index to form X-VERIFY header
const xVerify = `${sha256}###${PHONEPE_SALT_INDEX}`;

6.2 Order Status Check Checksum (GET /pg/v1/status/{mid}/{transactionId})

// Concatenate status endpoint path + Salt Key
const endpointPath = `/pg/v1/status/${PHONEPE_MERCHANT_ID}/${merchantTransactionId}`;
const stringToHash = endpointPath + PHONEPE_SALT_KEY;
const sha256 = crypto.createHash('sha256').update(stringToHash).digest('hex');
const xVerify = `${sha256}###${PHONEPE_SALT_INDEX}`;

6.3 Webhook Callback Verification

// Extract x-verify from incoming headers
const receivedXVerify = headers['x-verify'];
const base64Response = req.body.response;

// Calculate expected signature
const stringToHash = base64Response + PHONEPE_SALT_KEY;
const calculatedSha256 = crypto.createHash('sha256').update(stringToHash).digest('hex');
const expectedXVerify = `${calculatedSha256}###${PHONEPE_SALT_INDEX}`;

if (receivedXVerify !== expectedXVerify) {
  throw new Error('Invalid signature on incoming PhonePe webhook');
}
